# Platen

Print, scan and copy for Windows 11, straight over the network: IPP printing with real presets, custom picture sizes and exact photo sizes for frames, scanning with OCR, and the queue and ink levels in the tray. Part of the Nocturne apps. No telemetry.

## Download

**[Download Platen-Setup.exe](https://github.com/Bifflord146/platen-releases/releases/latest/download/Platen-Setup.exe)** (Windows 10/11, 64-bit)

Run it. It installs for your Windows account only (no administrator prompt) and adds Platen to the Start menu under **Nocturne**. To remove it: Settings › Apps › Installed apps › Platen › Uninstall. Your settings are kept in case you reinstall.

> Windows may say "Windows protected your PC" because the installer isn't code-signed. Click **More info**, then **Run anyway**.

## Updates

Platen updates itself. It checks this page when it opens and every few hours, downloads a newer version in the background, and installs it when you close Platen. Nothing else is sent anywhere.

This repository holds the built app only; there is no source code here.
